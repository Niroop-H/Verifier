EDA verification workflows

Core adapters have reproducible regression fixtures. Optional stages remain blocked or not run when required inputs are absent.

RTL lint and compile

Simulation

Icarus + VVP execute a self-checking testbench with explicit assertions on outputs.

Logs and input hashes retained
CI regression

Synthesis

Yosys hierarchy checking, process lowering, optimization and structural/statistical reports.

Not physical sign-off
CI regression

Formal properties

SymbiYosys with Z3 runs supplied tasks: a true property passes and a false property produces a counterexample.

Bounded results are not unbounded proofs
CI regression

VHDL analysis

GHDL analyzes valid VHDL and rejects intentionally malformed input. Functional coverage requires testbenches.

Standards and assurance mappings

The platform can organize check results and evidence against applicable criteria. Listing a standard is not a claim of certification, regulatory approval or full compliance.

IEEE 1800 — SystemVerilog

HDL source, lint, compilation and simulation mapping; language coverage depends on the selected tool.

IEEE 1076 — VHDL

VHDL analysis and elaboration mapping through GHDL; functional verification requires testbenches/assertions.

IEEE 1800.2 / UVM

Verification methodology mapping. UVM libraries, supported simulator, project testbench and regression setup may be required; there is no universal built-in UVM engine claim.

DO-254

Potential design-assurance workflow mapping for applicable airborne electronic hardware. This tool does not certify DO-254 compliance.

MIL-STD-883

Potential evidence mapping for applicable microcircuit test methods. Physical tests require suitable devices, equipment and laboratories.

MIL-PRF-38535

Potential manufacturing/quality evidence mapping where contractually applicable; no microcircuit certification is implied.

NIST SP 800-171 / CMMC

Information-protection control mapping for applicable workloads/contracts. No cloud authorization or CMMC assessment is claimed.

FIPS 140-3

Cryptographic-module assurance reference where applicable. This page does not imply a validated cryptographic module is used.

FedRAMP / DoD cloud impact levels

Deployment and data-handling considerations for applicable US government workloads. No authorization is claimed.

ITAR / EAR and national requirements

Applicability depends on technology, parties, jurisdiction and classification. Use approved environments and legal review where required.

Release boundary: PASS applies only to the named executed check. Missing tools/collateral produce BLOCKED; omitted checks are NOT RUN. Session 1 is not a universal verification engine, foundry sign-off service, defence certification or fabrication-readiness determination.
