RTL Workbench

Submit Verilog RTL and a testbench to an isolated Linux runner with Icarus Verilog and VVP. Review compile and simulation logs from the actual run.

REAL TOOL RUN · ICARUS VERILOG
Design inputsVerilog · .v
Limits: RTL 40 KB · testbench 20 KB · maximum runner time 5 minutes. Never submit confidential or export-controlled designs to this demo.
Run status
Ready to run
Load your RTL and testbench, then select Run RTL simulation.
Scope: this workbench runs Icarus compile + VVP simulation only. A PASS means that the simulator process completed successfully; it does not prove the design is functionally correct unless your testbench asserts expected behaviour. This is not formal proof, timing sign-off or fabrication readiness.
How it works
1
Submit sources
RTL and testbench are sent to the API.
2
Isolated execution
GitHub Actions installs Icarus Verilog on a fresh Linux runner.
3
Inspect evidence
Open the run and download compile logs, simulation logs and JSON result artifact.

If the API reports that the runner is not configured, the Vercel project still needs the GitHub token environment variable and a redeployment.
